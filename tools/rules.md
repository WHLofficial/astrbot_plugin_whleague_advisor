# WHL 联赛规则速查（whl_rules_lookup 数据源）

> 用途：whl_rules_lookup 的检索语料。每条一个 `## ` 小节；工具按关键词命中返回
> 小节原文，不接 LLM 生成。出处为平台仓源码与规则编号，插件只读不改平台仓。
> 金额单位 m（百万）；工资单位 m/半赛季；转会窗刻度 = 已关常规窗数（service ticks）。

## 转会窗与赛季节奏

开窗期（转会窗 open）= 休赛期：没有联赛比赛，挂牌、出价、报价、谈判都活跃；关窗后进入无开窗期（赛季进行中），市场冷下来。关窗是事件，不是整个赛季进行期。转会窗序号 windowSeq 按赛季内第几次开窗计。球员谈成的新合同「关窗后生效」：关窗那一刻才写进合同，关窗前的交易仍按老合同算。
出处：GLOSSARY.md「赛季与转会窗」「待生效/关窗后生效」；平台 `/api/seasons/current` 的 window.status。

## 挂牌价上下限

挂牌价（4.4.1.1）：下限 = max(1, ceil(min(0.5×违约金（RC）, 0.5×平台身价（marketValue）)))，上限 = floor(1.5×违约金（RC）)。平台身价（marketValue）缺失时下限只用违约金（RC）项。下限 > 上限（违约金（RC）过低）时挂牌不可行。出价必须为整数：首笔出价不得低于挂牌价，抬价至少比当前最高价多 1m。
出处：src/core/market-rules.ts listingPriceBounds / validateBidAmount（规则 4.4.1.1/4.4.1.2）。

## 竞价截止判定

挂牌次日起，在交易日 18:00–23:00 时段内找「自上一出价起连续静默小时数无新出价」且整段落进时段的最早时刻；落不下顺延到下一交易日。无人出价的挂牌同样判定（以挂牌时刻为静默起点）；强制拍卖最早判定日 = 挂牌日 + 2 天。4.4.7：无人接价即流拍。下架费 = 挂牌价的 10%（窗口收尾无人出价时由挂牌方支付）。
出处：src/core/market-rules.ts bidDeadline / delistFee（规则 4.4.7/4.4.8）。

## 激活（挖人）

激活金额（4.4.2.3，非训练营）：保护期内违约金（RC）≤20m → 2 倍，违约金（RC）>20m → 1.5 倍；保护期外 1 倍违约金（RC）。刚签约（效力为 0）的球员不可被激活，要等常规窗关窗；同一窗对同一人只能激活一次（失效激活也占额）。激活后要在 QQ 私信通知被激活方主教练（含激活方名、球员名、竞价匹配提醒），并上传激活通知截图作为凭证。
出处：src/core/bypass-rules.ts activationFee；src/worker/activations.ts；GLOSSARY.md「激活」。

## 保护期

保护期 = 合同上的防挖墙脚时期：期内被激活要付溢价（违约金（RC）的 1.5–2 倍），出了保护期按违约金（RC）原价。正式合同保护期 = 签约基数 + 3 个转会窗；训练营合同无保护期。「明确放人」（拒绝球员要求时点的决定）后果之一就是保护期立即结束，同时全联盟通告并挂「不满」标记。
出处：src/core/bypass-rules.ts PROTECTION_TICKS / protectionTicksFor；GLOSSARY.md「保护期」「明确放人」。

## 解约费

解约（4.4.4）：效力满 3 年（6 个常规窗）免费解约；其余 = 违约金（RC）× (3 − 效力年数) × 0.1。解约后球员变自由身。
出处：src/core/bypass-rules.ts terminationFee（规则 4.4.4，FREE_TERMINATION_SEASONS=3）。

## 违约金（RC）与改价区间

新违约金合法区间（4.3.1，谈判时改违约金（RC）的边界）：旧违约金（RC）≤ 20m → ±10m；旧违约金（RC）> 20m → ±50%；下限至少 1m，整数。违约金（RC）是挂牌上限和激活溢价的基数，不是球员估价；挂牌上限 1.5×违约金（RC）、激活溢价以违约金（RC）为基数。
出处：src/core/negotiation-rules.ts releaseFeeBounds（规则 4.3.1）。

## 训练营球员合同

训练营合同双固定（4.3.4(1)）：工资 0.75m/半赛季、违约金固定 5m；无保护期。训练营球员激活金额固定 5m（4.4.2.3(3)，不受挂牌上下限规则限制）。训练营球员不进一线队球员市场曲线，估价走激活成本口径。
出处：src/core/negotiation-rules.ts TRAINEE_WAGE/TRAINEE_RELEASE_FEE；src/core/market-rules.ts TRAINEE_ACTIVATION_FEE。

## 能力等级（1–10）

CA（当前能力）/PA（潜力）→ 能力等级 1–10（§6.7 公开映射）：≥93→10、≥90→9、≥87→8、≥84→7、≥80→6、≥75→5、≥70→4、≥65→3、≥60→2、else 1。年龄 ≤ 成长年龄（默认 25）时取 (CA 等级 + PA 等级)/2（可 0.5 步进），否则取 CA 等级。
出处：src/core/negotiation-rules.ts ratingLevel / abilityLevel。

## 球员要求（涨薪）与转会申请

球员要求 = 球员在开窗期主动提出的新合同诉求（涨工资、提高违约金）。三轮还价没谈拢、或三天没回应到期 = 「没谈成」。被拒绝的球员可提交转会申请（挂着期间俱乐部不能给他续约）。主教练在拒绝确认里点「明确放人」→ 保护期结束、全联盟通告、挂「不满」；「不满」期间若要求里带折价威胁，激活费按折后价。
出处：GLOSSARY.md「球员要求（闹涨薪）」一节。

## 工资与谈判预期

平台预期工资 expectedWage = a·等级^b·RC^c（谈判引擎口径，单位 m/半赛季，n=539 拟合 R²≈0.92），只回答「他的工资相对同档预期偏高/偏低」（gap <0.8 underpaid / >1.2 overpaid），不参与市场估价、不反推违约金（RC）。工资帽等参数走管理端配置。
出处：src/worker/negotiation-secret.ts（涉密模块，只读口径）；插件设计文档 §5.3。

## 平台身价（marketValue）与插件估价口径

平台 marketValue 列生产全为 NULL，不可当价格锚。插件给的「市场参考价」来自公开价格曲线（挂牌价/强制拍卖成交/转会广告板标价拟合，log(price)=a+b·log(level)+角色修正，n=29、R²≈0.72）；「可成交区间」= 市场参考价与 [0.5×违约金（RC）, 1.5×违约金（RC）] 挂牌合法区间的交集。任何回答不说「官方身价」。
出处：插件设计文档 §5.1/§5.3；src/core/market-rules.ts listingPriceBounds。

## 交易税

买球员的交易税打在卖方（卖方到账 = 成交价 − 税），不做缴池。税率为管理端可配置参数。
出处：平台经济规则手册 §3.4 红线 3（memory/rules-s9-economy-plain.md）。

## PlayStyle（徽章）

一名球员最多 15 个槽（12 银 + 3 金），每槽一枚 PlayStyle；来源 = FC 档案自带 + 平台发放（成长方案/中国计划/消费中心/管理组）。银金互斥：有金版银版就不显示，金版移除后银版自动回来。外场球员拿不到 6 个门将专属项。头页 🥇×N 🥈×N 数的是「FC 自带 + 发放所得」总和，不是只数发放。
出处：GLOSSARY.md「PlayStyle」一节。

## 消费券与俱乐部资金

俱乐部资金两层：现金余额 + 消费券（只能消费抵扣、先券后钱，不可转账不可兑现；来源 = 建设返还 + 事件发放 + 管理组发放）。报价冻结押金不算可用余额（可用 = 余额 − 冻结）。
出处：GLOSSARY.md「候选名单与消费券」；平台经济规则手册 §2。
